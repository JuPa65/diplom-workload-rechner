# Diplom-Workload-Rechner mit Lerntagebuch

Rechner für Studierende des Diplomstudiengangs gehobener Polizeivollzugsdienst an der FHSV Saarland (Schlüsselkompetenzen I, Ziel- und Zeitplanung).

Aufruf: https://jupa65.github.io/diplom-workload-rechner/

<img src="qr/QR_Diplom-Workload-Rechner.png" alt="QR-Code zum Workload-Rechner" width="180">

- Alle Fächer mit ihren LVh aus der Stundentafel (Studienplan 2024, Anlage 1) und die Prüfungen nach APO g. D. Pol. sind vorbelegt.
- Selbststudium-Faktoren und Prüfungsvorbereitung sind Normalwerte aus der Workload-Untersuchung 2026 (Grundstudium: Theorie 0,47, Recht 0,56, Klausurvorbereitung LVh × 0,46).
- Lerntagebuch zum Messen des eigenen Faktors.

Datenschutz: Alle Eingaben bleiben im Browser des eigenen Geräts (localStorage). Nichts wird an einen Server übertragen, nichts landet im Repository.

Aufruf: https://jupa65.github.io/diplom-workload-rechner/
